## 字段说明

- `Gap`：Ordered Indexer 结束到 Plan 开始的时间差。
- `Busy`：两个目标 kernel 执行区间并集，不重复累计重叠的 AIC/AIV 时间。
- `Chain`：首个目标 kernel 开始到最后一个目标 kernel 结束，包含 kernel 间隙。
- `Joint/Fallback/Single`：联合执行组数／容量溢出回退组数／单行有序路径组数。
- `Desc`：Plan 输出的 transfer descriptor 数量。
- `Result`：输入、TopK 集合、持久状态、输出及保护区的完整校验结果。
