# 官方 Indexer 与 Ordered Indexer＋BT Direct Odd Plan 20 样本对照

## 结论

- 18 个工况全部通过正确性门禁：官方与 Ordered Indexer 的有效 TopK token 集合逐行一致。
- MTP3 的每个请求均走 4 行联合 Plan：32～64 行对应 8～16 组联合，全部为 0 组回退。
- 每行初始缓存恰好命中 1843/2048（90%），miss 205；每请求使用满 capacity=8192。
- kernel 间隙在所有正式工况的 P50 都是 0.022μs。性能差异主要来自独立 Plan，而不是两条 kernel 的下发间隙。
- 512 优化线程生效；1024 线程是逐行兼容回退路径，本轮没有触发。
